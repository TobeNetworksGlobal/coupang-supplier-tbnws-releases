# 쿠팡 서플라이어 자동화 (투비) — 배포 채널

이 저장소는 **소스가 없습니다.** 설치 파일과 자동 업데이트 메타데이터(`latest.yml`)만 릴리스로 올라갑니다.

## 설치

[Releases](../../releases/latest) 에서 `coupang-supplier-tbnws-Setup-<버전>.exe` 를 받아 실행하세요.

설치할 때 **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행** 을 눌러 주세요. 코드 서명이 없어 나오는 안내이며 정상입니다.

## 투비 플러그인

발주서 검증·이플렉스 출고·로케이션 이동 같은 투비 전용 기능은 앱에 포함되어 있지 않습니다. 별도 채널에서 `.csplugin` 을 받아 앱에서 가져오세요.

- 플러그인 채널: https://github.com/BOSEON-SEO/coupang-supplier-releases-tbnws/releases/latest
- 적용: 앱 → 설정 → 플러그인 → 가져오기 → 재시작

## 자동 업데이트

앱이 이 저장소의 `latest.yml` 을 보고 새 버전을 감지합니다. 자동으로 받지는 않고, 사용자가 동의하면 내려받아 설치합니다.

## 릴리스에 올라가는 파일

| 파일 | 용도 |
|---|---|
| `*.exe` | 설치 파일 |
| `*.exe.blockmap` | 차등 업데이트용 블록 맵 |
| `latest.yml` | 버전·sha512·릴리스 노트. **이게 없으면 자동 업데이트가 동작하지 않습니다** |
